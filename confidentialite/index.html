Politique de confidentialité

En bref : nous ne collectons rien. Les chiffres que vous saisissez restent sur votre appareil.

Les calculs se font dans votre navigateur

Le diagnostic et le simulateur solaire s'exécutent entièrement sur votre appareil. Aucune valeur saisie n'est transmise à Kahraba Check ni à un tiers.

Ce qui est gardé sur votre appareil

Pour vous éviter de tout ressaisir, le tableau du diagnostic est enregistré dans le stockage local de votre navigateur. Il n'en sort jamais. Le bouton « Vider le tableau » l'efface, tout comme la suppression des données du site dans votre navigateur.

Pas de cookie, pas de mesure d'audience

Le site n'utilise ni cookie, ni outil de mesure d'audience, ni publicité. Les polices de caractères sont servies par le site lui-même, sans appel à un service tiers.

Hébergement

Comme tout hébergeur, GitHub Pages peut enregistrer des données techniques de connexion (adresse IP, date, page demandée) pour assurer la sécurité du service. Ces données sont traitées par GitHub selon sa propre politique de confidentialité.

Si vous nous contactez

Si vous nous envoyez vos factures par WhatsApp ou par e-mail, elles servent uniquement à réaliser votre diagnostic et ne sont jamais revendues. Vous pouvez demander leur suppression à tout moment. Ces traitements seront déclarés à la CNDP, conformément à la loi 09-08, avant le démarrage de l'activité commerciale.
